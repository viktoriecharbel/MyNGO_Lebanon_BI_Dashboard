# MyNGO Humanitarian Dashboard

## Objective

Develop an interactive Power BI dashboard to support humanitarian programme decision-making.

The dashboard will help programme managers understand:

- geographic coverage
- beneficiary reach
- programme performance
- resource allocation

## Tools

- Power BI Desktop
- Power Query
- DAX
- SQL
- Python

## Context

Fictional humanitarian organisation operating in Lebanon.

Public humanitarian datasets are combined with simulated operational programme data.
